# Practica1
Uso de aplicaciones colaborativas para el uso de herramientas de Inteligencia Artificial

Definición del proyecto: Formulan un problema que pueda ser resuelto con las librerías/bibliotecas estudiadas.

La información de entrada debe estar en un archivo CSV, Excel, JSON, etc.
Configuración del entorno: Usar un entorno local y un entorno en la nube.
Presentar como solución un solo Notebook, indispensable que se use visualización de información.
Consideraciones particulares sugeridas:

Crear un proyecto y un notebook en la herramienta seleccionada.
Pasar los registros a un dataframe de pandas del conjunto de datos.
Agregar cuatro columnas al dataframe, en función de los datos originales.
Generar dos visualizaciones del dataframe.

# Problema
El problema a resolver consiste en analizar un conjunto de datos de ventas almacenado en un archivo CSV mediante un entorno colaborativo en la nube como Google Colab, transformando la información en un DataFrame de Pandas al que se le agregan nuevas columnas derivadas de los datos originales, y generando visualizaciones que permitan identificar patrones relevantes —como los cinco productos más vendidos y la evolución mensual de las ventas— con el fin de facilitar la comprensión y toma de decisiones basadas en la información.
